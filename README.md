# 5-Stage-Pipelined-RISC_V-CPU-with-Dynamic-Branch-Prediction
A 5-stage pipelined RV32I CPU in Verilog featuring EX/ID forwarding, hazard detection, load-use and branch RAW handling, ID-stage branch resolution, speculative fetch using a dynamic 2-bit branch predictor + BTB, and misprediction recovery. Optimized to reduce loop-related control hazard penalties.
